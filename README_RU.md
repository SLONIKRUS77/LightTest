# LightTest CLI

**LightTest CLI** — сверхлёгкая утилита для проверки скорости сети на
малопроизводительных компьютерах, небольших серверах и безголовых Linux-системах.
У программы нет графического интерфейса и фоновых служб: запустите проверку,
когда она нужна, и завершите работу.

При каждом запуске утилита определяет публичный IP-адрес и провайдера,
проверяет базовую ICMP-задержку до Cloudflare (`1.1.1.1`) и Google (`8.8.8.8`),
а затем измеряет скорость загрузки и отправки данных через `speedtest-cli`.
Результаты выводятся в рамке с бирюзовой и фиолетовой подсветкой и сохраняются
локально в CSV, JSON или текстовом формате.

## Требования

- Python версии 3.8 или новее
- Системная команда `ping` для проверки базовой задержки
- Подключение к интернету

Для определения IP используется публичный HTTPS API ipinfo без токена. Измерение
скорости подключается к серверу Speedtest.net, выбранному библиотекой
`speedtest-cli`. Во время проверки эти сервисы получают публичный IP-адрес вашей
сети. Если API определения IP недоступен, ошибка будет показана, но тест скорости
продолжится.

## Установка из исходного кода

```bash
python3 -m pip install -r requirements.txt
python3 -m pip install .
lighttest
```

Запуск без установки команды:

```bash
python3 main.py
```

## Отдельный бинарный файл для Linux

Соберите исполняемый файл на Linux-машине и для той же архитектуры процессора,
на которой планируете его запускать:

```bash
python3 -m pip install -r requirements.txt
python3 -m PyInstaller --clean --onefile --name lighttest main.py
./dist/lighttest
```

Готовый `dist/lighttest` содержит Python и необходимые пакеты. Бинарные файлы
PyInstaller зависят от ОС и архитектуры; файл, собранный в одном окружении Linux,
не гарантированно запустится в любом дистрибутиве Linux.

## Параметры

```text
lighttest [--simple | --json | --share | --compact]
          [--export {csv,json,txt}]
          [--timeout СЕКУНДЫ]
```

- `--simple` — обычный многострочный текстовый отчёт.
- `--json` — полный результат, включая сведения о проверках ping, в stdout.
- `--share` — нераскрашенная ASCII-рамка для копирования в чат.
- `--compact` — одна строка для cron и скриптов.
- `--export csv|json|txt` — добавляет результат в `lighttest_history.csv`,
  `lighttest_history.json` или `lighttest_history.txt` в текущей папке.
- `--timeout СЕКУНДЫ` — тайм-аут сетевых запросов и ping (по умолчанию: `10`).

Примеры:

```bash
lighttest --share
lighttest --simple --export csv
lighttest --json --timeout 5
lighttest --compact >> speed-history.log
```

Режимы вывода взаимоисключающие. Экспорт можно совмещать с любым режимом.
История JSON хранится в виде массива результатов; CSV и текстовые отчёты
добавляются в конец файла.

## Для малопроизводительных устройств

LightTest — компактная утилита по запросу, а не панель мониторинга или фоновый
демон. Для работы не нужны браузер, база данных или постоянно запущенный процесс.
При этом тест скорости передаёт реальные данные, поэтому потребление ресурсов
зависит от выбранного сервера и скорости сети.
